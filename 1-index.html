What it does

1. Measures loudness (ITU BS.1770 / EBU R128, the standard streaming sites use) and true peak (4x oversampled, so it catches peaks between samples).
2. Changes the volume to hit your target. If that alone keeps peaks under the ceiling, nothing else is touched.
3. If peaks would go over, a lookahead limiter smooths only those peaks, then it re-measures and corrects to land on the target.
It does not change EQ or fix the mix, and it can't undo clipping already baked into the file. It measures, it does not listen: always play the result before you upload.
